# Walkie Talkie Pro — نسخه گروهی (نمونه اولیه)

## امکانات
- ساخت گروه با کد یا ورود به گروه با همان کد
- محدودیت ۱۰ عضو در هر گروه
- دکمه Push-to-Talk: فقط وقتی دکمه نگه داشته شود، میکروفون ارسال می‌کند
- صدای زنده بین اعضا با WebRTC
- سرور WebSocket برای هماهنگ‌کردن اتصال‌ها

## اجرای محلی برای آزمایش
نیاز به Node.js نسخه 18 یا جدیدتر:
1. فایل ZIP را از حالت فشرده خارج کن.
2. در پوشه پروژه اجرا کن:
   `npm install`
   `npm start`
3. روی همان دستگاه، `http://localhost:3000` را باز کن.
4. برای گوشی‌های دیگر در یک شبکه، به HTTPS یا راه‌اندازی امن متناسب با شبکه نیاز است؛ `getUserMedia` در مرورگرها معمولاً فقط روی HTTPS یا localhost مجاز است.

## استفاده روی اینترنت (رایگان تا حد امکان)
برای صحبت از شبکه‌های مختلف، پروژه را روی یک سرویس میزبانی Node.js که WebSocket و HTTPS را پشتیبانی می‌کند مستقر کن. معمولاً روند کار:
1. یک مخزن Git بساز و این فایل‌ها را در آن قرار بده.
2. سرویس میزبانی Node.js انتخاب کن که پلن رایگان فعلی داشته باشد.
3. دستور build لازم نیست؛ start command برابر `npm start`.
4. URL عمومی HTTPS را روی هر گوشی باز کن.
5. یک نفر کد گروه را بسازد و برای بقیه بفرستد؛ دیگران همان کد را وارد کنند.

شرایط پلن رایگان سرویس‌های میزبانی تغییر می‌کند و ممکن است خوابیدن سرویس یا محدودیت مصرف داشته باشد؛ رایگان‌بودن دائمی تضمین نیست.

## محدودیت‌های مهم
- این نسخه یک نمونه اولیهٔ کد است، نه سرویس عمومیِ میزبانی‌شده؛ لینک اینترنتی آماده یا APK تولید نشده است.
- WebRTC در شبکه‌های ساده ممکن است با STUN وصل شود؛ بعضی شبکه‌ها به TURN server نیاز دارند که ممکن است هزینه داشته باشد.
- معماری فعلی برای هر نفر اتصال مستقیم جداگانه می‌سازد (mesh). برای ۱۰ نفر، مصرف پهنای‌باند و پردازش می‌تواند بالا برود؛ برای محصول قابل‌اعتماد بهتر است SFU مثل LiveKit/mediasoup استفاده شود.
- کد گروه به‌تنهایی احراز هویت نیست؛ برای استفاده حساس، رمز گروه/دعوت‌نامه، محدودسازی درخواست‌ها و امنیت بیشتر اضافه شود.
- ارتباط صوتی زنده ممکن است به مجوز میکروفون و اجازه پخش خودکار صدا در مرورگر نیاز داشته باشد.
- اگر صدای گروه وصل نشد، TURN server را پیکربندی کن؛ در این نمونه سرور TURN سفارشی تنظیم نشده است.

## ساختار
- `server.js`: سرور HTTP و WebSocket سیگنالینگ
- `public/index.html`: رابط فارسی و منطق WebRTC
